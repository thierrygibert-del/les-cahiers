## Arborescence et responsabilités

- `feuilleter.html` : édition illustrée officielle de **10 cartes**, parcours de découverte. Ce format ne doit pas être appelé « rapport intégral ».
- `index.html` : contre-enquête **intégrale**, avec chapitres, références et état des vérifications.
- `avant-premiere.html` : **redirection** vers `feuilleter.html` pour ne pas rompre les liens déjà diffusés.
- `archives/` : anciennes maquettes et lecteurs, conservés pour la traçabilité ; ne pas réutiliser comme édition publique.
- Le PDF consolidé sur WordPress correspond au texte documentaire arrêté au **13 novembre**, et non aux dix cartes graphiques du 14 novembre.
- La copie HTML Drive de l'étude intégrale du 13 novembre est **identique octet pour octet** au fichier GitHub `index.html` (contrôle des contenus réalisé le 14 novembre) : [copie de production](https://drive.google.com/file/d/16ZmSuktXcBYQ1Q_zkbwKcqdmd3Sd8lYu/view). L'édition illustrée actuelle `feuilleter.html` n'a pas de copie HTML brute certifiée dans Drive ; ne pas utiliser l'ancienne maquette intitulée ARCHIVE.
- Le PDF du **4 octobre** reste accessible dans l'article initial comme document historique.

## Règles de mise à jour

1. Réviser les preuves et les conclusions dans le document maître Drive et tenir à jour la ligne NAZA du tableau de suivi.
2. Mettre à jour la version intégrale `index.html` en respectant les états de preuve.
3. Si une carte doit changer, mettre à jour `feuilleter.html`, contrôler les dix cartes et leurs sources.
4. Vérifier ensuite les liens depuis WordPress et la publication GitHub Pages.
5. Conserver dans `archives/` les étapes de fabrication utiles, sans créer plusieurs fichiers portant le statut « FINAL ».
6. Ne jamais présenter une illustration éditoriale ou un schéma conceptuel comme une preuve de terrain.

## Points de vérification encore ouverts

- « 500 victimes civiles anticipées pour une seule frappe » : affirmation **contestée, non établie par les pièces publiques** ; à distinguer du chiffre quotidien cumulé étudié par le *New York Times*.
- Recontrôler directement l'audio hébreu des deux passages contestés et leurs sous-titres, avec timecodes et traduction indépendante.
- Demander ou identifier une pièce opérationnelle attribuable à une frappe précise pour les allégations portant sur le chiffre 500.
- Vérifier la provenance des plans de montage contestés, notamment dans le dossier Lanzmann / Ribot.
- Les producteurs annoncent plus de 100 sources ; cette déclaration ne rend pas vérifiable la totalité de leurs documents confidentiels.
